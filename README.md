# jobwatch - התראת משרות בזמן אמת

סקריפט קטן שבודק כל 5 דקות את מערכות הגיוס של החברות (לא דרך אתרי הסינון), מסנן לפי התפקיד והאזור שלך, ושולח לטלפון התראה שפותחת את המשרה בלחיצה.

## למה כך ולא סריקה של LinkedIn / Indeed
האתרים האלה אוסרים סריקה אוטומטית בתנאי השימוש שלהם וחוסמים אותה, ולכן הסקריפט לא נוגע בהם. הוא קורא ישירות את מערכות הגיוס של החברות (Workday, Greenhouse, Lever), שם המשרה מתפרסמת קודם, ולפעמים שעות לפני שהיא מגיעה ללינקדאין. את LinkedIn ו-Indeed מכסים עם התראות מובנות (ראה למטה).

## הקמה (כ-10 דקות)
1. **טלפון:** התקן את אפליקציית **ntfy** (חינם), הירשם לנושא עם שם ארוך וייחודי, למשל `eli-jobs-x7k29q`. מי שמכיר את שם הנושא יכול לקרוא אותו, לכן שם ארוך.
2. **GitHub:** צור repository **ציבורי** (ריצות חינמיות ללא הגבלה) והעלה את כל התיקייה, כולל `.github`.
3. **Secrets:** ב-Settings > Secrets and variables > Actions הוסף `NTFY_TOPIC` עם שם הנושא. אופציונלי: `TELEGRAM_TOKEN` ו-`TELEGRAM_CHAT_ID`.
4. **הפעלה:** בלשונית Actions הפעל את ה-workflow ולחץ Run workflow. בריצה הראשונה הוא שומר את המשרות הקיימות בשקט ושולח הודעה אחת "jobwatch is live". משם, כל משרה חדשה שמתאימה תקפיץ התראה.

## התאמה אישית (`config.json`)
- `include` / `exclude` / `hot`: מילות מפתח בכותרת. משרות `hot` מגיעות בעדיפות גבוהה.
- `locations`: ערים. משרה בלי מיקום ברור עוברת.
- חברות נוספות: ב-Workday העתק מכתובת עמוד הקריירה את ה-host וה-site (למשל `dell.wd1.myworkdayjobs.com/External`), שנה `enabled` ל-`true`. ב-Greenhouse וב-Lever מספיק ה-slug מהכתובת.
- ל-Dell ול-Medtronic השארתי כתובות שלא הצלחתי לאמת, לכן הן כבויות עד שתבדוק.
- בדיקה מקומית: `python jobwatch.py --dry-run --notify-existing` מדפיס מה היה נשלח.

## השכבה השנייה: התראות מובנות באתרים (בלי קוד)
- **LinkedIn:** חיפוש "QA" / "Professional Services Engineer" / "Support Engineer" באזור חיפה, סינון "Past 24 hours", ואז Set alert עם התראת דחיפה באפליקציה. חזור על זה לכל תפקיד.
- **Indeed, AllJobs, Drushim, JobMaster:** אותו דבר, חיפוש שמור עם התראה.
- **Follow לחברות** (NVIDIA, Harmonic, Dell, Medtronic, Mobileye) בעמוד ה-LinkedIn שלהן.

## כדי להיות ראשון
החזק מוכנות: גרסת CV ל-QA וגרסה ל-Professional Services, ומכתב קצר שאפשר להתאים בדקה. ברגע שההתראה מגיעה: פתח, התאם משפט אחד לתיאור המשרה, הגש, ואז שלח הודעה למגייס.

## מגבלות
- GitHub עלול לעכב ריצה במספר דקות בזמני עומס.
- אם מערכת גיוס משנה מבנה, המקור יופיע כ-ERROR בלוג הריצה ולא ישבור את השאר.
- לא נבדק מול האתרים החיים מהסביבה שבה נכתב. בדוק עם `--dry-run` לפני שאתה סומך על זה.
